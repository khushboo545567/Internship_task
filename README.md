# E-Commerce Admin Dashboard

A responsive E-Commerce Admin Dashboard. The dashboard allows administrators to monitor store statistics and manage products through a clean and responsive interface.

## Features

### Dashboard

The dashboard provides an overview of the store with:

- Total Products
- Total Orders
- Total Revenue
- Pending Orders
- Recent Orders

### Product Management

The Products section provides complete product management functionality.

Features include:

- View products in a table
- Search products by name
- Filter products by category
- Filter products by status
- Sort products by price
- Sort products by stock
- Add new products
- Edit existing products
- Delete products
- Responsive product table


### Responsive Design

The dashboard is designed to work across:

- Desktop
- Tablet
- Mobile
